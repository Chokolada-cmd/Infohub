Step 2: Variables - Boxes for Information

A variable is a labeled box where you store information. You give it a name, and you put a value inside.

let score = 0;   // a box called "score" holding 0

const name = "Ada";   // a box that can't be reassigned

Match the keyword to its meaning

let - a changeable box
const - a permanent box

Step 4: Operators & Conditionals

Operators let you do math and comparisons. Conditionals let your code make decisions.

Arithmetic: + - * /

Logic: && (and) || (or) ! (not)

Step 5: Functions - Reusable Machines

A function is a reusable block of code. You define it once, then call it whenever you need it.

function greet(name) {

  return "Hello, " + name + "!";

}

greet("Ada"); // -> "Hello, Ada!"

Step 6: Arrays & Loops

An array holds a list of values. A loop repeats code for each item in the list.

let colors = ["red", "green", "blue"];

colors.forEach(function(c) { console.log(c); });
